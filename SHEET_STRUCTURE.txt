FEATURES
- Admin creates Test 1, Test 2, Test 3…
- Admin adds questions to each test.
- Student dashboard displays all active aptitude tests.
- A student can submit each aptitude test only once.
- Marks are calculated automatically and saved in TestResults.
- Admin selects present students using checkboxes; all remaining students are automatically marked Absent.
- Admin can view all attendance records.
- Student dashboard displays only that student's attendance records and attendance percentage.
- The dashboard loads aptitude tests, results, and attendance independently so one failed section does not hide the others.
- Code.gs automatically creates missing support tabs with the correct headers. Registration data is not deleted or replaced.


TEST RESULT LEADERBOARD
- Every submitted test is saved in TestResults automatically.
- Highest scorer is calculated automatically after each submission.
- Admin Dashboard > Results shows highest scorer(s) for each conducted test and all detailed results.
- Main Dashboard (index.html) shows only Student Name and Score; no email, roll, department, mobile, or other student details are exposed.
